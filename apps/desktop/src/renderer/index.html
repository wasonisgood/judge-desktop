    AI 服務

    工作負載身分聯合：操作步驟

    由提供者代為連線時，您不需要自己申請金鑰。請依下列四步完成設定。

    1. 一

      向提供者取得三組代碼

      組織 ID、聯合規則 ID（fdrl 開頭）、服務帳號 ID（svac 開頭）。這三組代碼由提供者在 Claude Console 中建立。

    2. 二

      準備身分憑證（JWT）檔案

      由您自己的身分提供者（例如 GitHub Actions、Google 或自架的 OIDC 服務）發出身分憑證，存成一個純文字檔。每次連線時程式都會重新讀取這個檔案。

    3. 三

      在下方填入設定

      依序填入組織 ID、聯合規則 ID、服務帳號 ID，以及身分憑證檔案的完整路徑。規則涵蓋多個工作區時，才需要填工作區 ID。

    4. 四

      按「儲存」，再按「測試連線」

      看到「連線成功」即完成。若顯示失敗，請確認身分憑證是否過期、檔案路徑是否正確，並向提供者確認規則設定。

    一般

    法條沿革與法名確認會永久保存；現行法規全文保存 30 天。判決內頁永久保存。

    金鑰只保存在這台電腦，並以系統的加密機制保護。本程式不會把金鑰傳給其他服務。

    助理會先確認再執行會花費 AI 額度或改動資料的操作。
