# 隱私說明 / Privacy Statement

## 中文

司法院裁判研究（以下稱本程式）是在使用者電腦上執行的桌面應用程式。

- **不收集個人資料。** 本程式沒有帳號系統，也不會把使用者的資料傳送給開發者。
- **檢索內容**：關鍵字與搜尋結果只保存在使用者電腦上（應用程式資料夾內的快取），快取期限可在設定中調整，也可以手動清除。
- **AI 金鑰**：使用者自行輸入的 AI 服務金鑰，以 Windows 的資料保護機制加密後保存在使用者電腦上。金鑰只會傳送給使用者設定的 AI 服務，不會傳送給開發者或其他第三方。
- **對外連線**：本程式會連線到司法院裁判書查詢系統（judgment.judicial.gov.tw）取得公開判決；使用 AI 功能時，會把判決原文傳送給使用者設定的 AI 服務。更新檢查會連線到 GitHub 取得最新版本資訊。
- **不使用追蹤或廣告工具。**
- **移除**：解除安裝時可選擇保留或刪除本機資料；也可以手動刪除應用程式資料夾。

聯絡方式：請在本 repo 開啟 Issue。

## English

Judge Research Desk (the "App") is a desktop application that runs on the user's computer.

- **No personal data is collected.** The App has no account system and does not send user data to the developer.
- **Search data**: keywords and search results stay on the user's computer in a local cache. The cache lifetime can be changed in Settings, and it can be cleared manually.
- **AI keys**: API keys entered by the user are encrypted with Windows data protection and stored on the user's computer. A key is sent only to the AI service the user configured, never to the developer or other third parties.
- **Outgoing connections**: the App connects to the Judicial Yuan judgment database (judgment.judicial.gov.tw) to fetch public judgments. When AI features are used, the judgment text is sent to the AI service the user configured. Update checks connect to GitHub to read the latest version information.
- **No tracking or advertising tools.**
- **Removal**: the uninstaller lets the user keep or delete local data; the application folder can also be deleted manually.

Contact: open an Issue in this repository.
